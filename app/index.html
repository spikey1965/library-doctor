How clean-up works

Clean up never deletes. It moves the copies marked Remove into this trash, then asks Plex and Radarr/Sonarr to rescan, so they don't go looking for them. Put Back returns a file to where it was. The trash empties itself after 7 days. Plex's own converted copies are left alone: remove those in Plex.
